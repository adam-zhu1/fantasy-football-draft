# data/

Put FantasyPros exports here (free account required). File names as FantasyPros downloads them:

- `FantasyPros_Fantasy_Football_Projections_QB.csv`, `_FLX.csv`, `_K.csv`, `_DST.csv` — season ("Draft") projections
- `FantasyPros_2026_Overall_ADP_Rankings.csv` — ADP for your scoring format

Stat columns are used, not the FPTS column, so any scoring preset works. `flags.csv` holds manual
committee overrides. `cache/` is filled automatically from nflverse on first run.
